# Number Guessing Game in Java

A console-based number guessing game created using Java.

## Features

- Generates a random number between 1 and 100
- Tells whether the entered guess is high or low
- Continues until the correct number is guessed
- Counts the total number of attempts

## Concepts Used

- Scanner
- Math.random()
- If-else statements
- Do-while loop
- Variables and user input

## How to Run

1. Compile: `javac Project.java`
2. Run: `java Project`
